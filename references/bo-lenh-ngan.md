# Bộ lệnh ngắn — Cooking Animation Skill

Use these short commands. Name the command used in each output.

- "Làm phim nấu ăn Anime này" — runs the full workflow: Phase 1 lock, Phase 2 breakdown, Phase 3 image prompts, Phase 4 video prompts, poster, SEO, then render and assembly, stopping for approval at every phase gate.
- "Làm breakdown món này" — runs Phase 2 only: 8 chronological scenes with ASMR sounds.
- "Làm image prompt món này" — runs Phase 3 only: character sheet first, then 8 JSON image prompts.
- "Làm video prompt món này" — runs Phase 4 only: 8 JSON video motion prompts.
- "Làm poster món này" — runs Step 4 only: one master poster prompt in one code block.
- "Làm SEO món này" — runs Step 5 only: 5 items, each in its own code block, plus the Word file on request.
- "Làm trọn gói món này" — runs all phases in order, without asking again between stages except at the phase gates the user has already approved.
