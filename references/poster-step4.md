# Poster — Step 4 (adapted)

Source rule: Step 4 Poster V2026.35, originally written for @cham.cinema. For cooking animation, keep the structure and laws, change the soul character to the cooking character and the channel and duration to the film in hand. Do not force a human teenager or parent into an animal cooking poster.

## Rules

- Output exactly one master poster prompt, in one code block.
- Format 9:16 vertical, 1080x1920.
- 4-layer vertical parallax:
  - Layer 1: title, 3D embossed gold, 15-28% at top (title itself 15-20% of frame height, in the top mobile safe zone), subtitle beneath, halo ring.
  - Layer 2: soul portrait of the main character, with golden swirl aura.
  - Layer 3: the kitchen setting in a realistic labour or home setting, looking up.
  - Layer 4: foreground macro prop, 30-40% at bottom, pushed against the lens, 3D pop-out.
- Title is a physical event from the script's material, not a flat font pasted on top. It must be readable in 0.5 seconds.
- Single Reference Lock: `@` symbols appear only once each, only in the `[INPUT ASSETS & CHARACTER BINDING]` block at the top of the prompt. The rest of the prompt uses pure names only.
- No real paper currency in posters. Use metaphorical props (for example, a slice, a pan, a notebook) instead.
- Present the poster for approval before rendering scenes.
