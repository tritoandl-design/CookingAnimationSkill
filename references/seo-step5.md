# SEO — Step 5 (adapted)

Source rule: Step 5 SEO for YouTube Shorts, originally written for @cham.cinema. For cooking animation, keep the structure and laws, change the channel and duration to the film in hand.

## Rules

- Pure Vietnamese, Mobile First.
- Title under 42 characters including `#Shorts`, target 30-41 characters, conflict or shock in the first 4-6 words.
- Title contains exactly one hashtag, `#Shorts`. No English title tail. No series labelling such as "Tập 1/Tập 2". Each Short stands alone.
- Package with exactly 5 items, each in its own separate code block for one-tap copy:
  1. SEO video filenames
  2. 3 title options
  3. SEO description with AI transparency
  4. Core channel keywords
  5. Pinned comment
- Export a Word file named `05_SEO_Phat_Hanh_[Ten_Phim_Khong_Dau].docx` when the user asks for the file version.
